# Codex Continuity website

The public launch page for [Codex Continuity](https://github.com/YesterdaysLemon/codex-continuity), built with React, Vinext, and OpenAI Sites.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

This starter does not use `wrangler.jsonc`.

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: verify the vinext build output
- `npm test`: build and verify the rendered product page
